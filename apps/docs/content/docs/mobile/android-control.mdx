Open [Nation Team Chat](https://thenation.city/swarm) in your browser. Use your workspace’s sign-in method or an access code supplied by its owner.

Access codes expire. If a code no longer works, ask for a new one. Keep pairing links private.

Your saved team and conversations remain in the workspace when you return.

[Contact NATION support](https://t.me/thenation_city).
