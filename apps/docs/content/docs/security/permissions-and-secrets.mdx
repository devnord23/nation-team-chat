title: Permissions and secrets
description: Help for your Nation Team Chat workspace.

Regular members use NATION API. Engine configuration, credentials, and model selection are restricted to the owner/admin area.

Review approval requests in the conversation. Check what an agent is asking to do before approving it, and stop the turn if the scope is unclear.

Keep access codes private. Use only the sign-in and connection flows provided by NATION.

[Contact NATION support](https://t.me/thenation_city).
