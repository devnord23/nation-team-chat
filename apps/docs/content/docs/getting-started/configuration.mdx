---
title: Configuration
description: Help for your Nation Team Chat workspace.
---

Open [Nation Team Chat](https://thenation.city/swarm) and sign in with the access method provided for your workspace.

Create an agent, give it a role, and send a clear first task. Include the result you want and any files it needs. The agent uses NATION API, managed by your workspace owner.

For shared work, create a group and add your agents. Mention an agent with `@` to address it directly. You can start chatting immediately; room setup is optional.

[Contact NATION support](https://t.me/thenation_city).
