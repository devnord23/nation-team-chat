# NATION Swarm loop

A 16-second, 1440×1440 product loop at 120 BPM: one NATION agent becomes the
Chief, grows a team, hands a task down the line, works inside an isolated PC,
signs with its own wallet, keeps its memory across a close and reopen, and
delivers a finished page that folds into the NATION column and back into the
agent it started as. The last frame flows into the first.

`nation-swarm.html` is the whole animation in one file (fonts inlined). Open it
in a browser to watch it live, or add `?t=12.5` to hold a single frame.

## How it is built

- **Everything is a function of time.** `seek(t)` draws frame `t`. No timers,
  CSS transitions or state carried between frames.
- **Closed-form springs.** Every animated value is a sum of spring step
  responses. Each sum returns to its starting value within the loop, and it
  is evaluated modulo the loop, so a spring that starts near the end is still
  ringing at the start. Position and velocity match across the seam for the
  object, the cursor and the camera. `checkTracks()` refuses to run if any
  value does not come back to where it began.
- **Edges, not boxes.** Morphing bodies move each edge on its own spring:
  leading edges fast, trailing edges behind.
- **Direct manipulation.** While the task is dragged it sits exactly under the
  cursor. On release it springs on from the cursor's position and velocity.
- **One object.** The Chief's body is the head at the start, the agent card,
  the Chief card, the deliverable, and the column's tile, then the head again.
  Build's body splits off it and becomes the PC, the tool strip, the wallet,
  its memory and a head of its own.

Palette: near-black `#020C01` is always an agent or its computer, white is
always work, and the logo green `#CDFFA6` appears only on the Chief's face,
the logo and the wallet's ready light. Type is Geist and Geist Mono.

## Files

| Path | What it is |
|---|---|
| `src/swarm.html` | Source of the animation (engine, timeline, drawing) |
| `nation-swarm.html` | Built single file: `tools/build.py` inlines fonts, the beat grid and the logo capital |
| `assets/nation-column-mark.svg`, `assets/nation-column-tile.svg` | The NATION column, rebuilt as vector from the founder's JPEG |
| `assets/fonts/` | Geist and Geist Mono (SIL Open Font License, `OFL.txt`) |
| `tools/compose_track.py` | Composes and synthesizes the original 120 BPM loop |
| `tools/analyze_beats.py` | Finds tempo, beats and the phrase downbeat in a track, numpy only |
| `tools/sfx.py` | Synthesizes the UI sounds at the cue times the page exports, mixes them under the music |
| `tools/render.py` | Playwright renders: stills, the per-beat review sheet, the video, the final MP4 |

## Rebuild everything

```sh
pip install numpy scipy pillow playwright==1.56.0   # Chromium: /opt/pw-browsers or `playwright install chromium`
apt-get install ffmpeg                              # needs libx264 and the tmix filter

python3 tools/compose_track.py out/music_loop.wav
python3 tools/analyze_beats.py out/music_loop.wav --loop --bars 8 --json out/beats.json
python3 tools/build.py
python3 tools/render.py sheet                       # one still per beat, 8 bars x 4 beats
python3 tools/sfx.py out/music_loop.wav out/audio_loop.wav
python3 tools/render.py video                       # 960 frames, 4 temporal subframes each, tmix-blended
python3 tools/render.py final                       # out/nation-swarm-loop.mp4
```

## Using a different track

1. Pick an 8-bar stretch that repeats cleanly, and cut it to start on the
   phrase's downbeat (`analyze_beats.py` without `--loop` reports tempo, beats
   and the phrase start).
2. Save the loop as a 48 kHz, 24-bit stereo WAV and run `analyze_beats.py`
   on it with `--loop`. The `grid` it writes to `out/beats.json` is what
   `build.py` puts into the page.
3. Rebuild, then re-run `sfx.py`, `render.py video` and `render.py final`.
   Every event is placed on beats, so the whole animation re-times itself.

The bundled track is original: it is generated by `compose_track.py`, with
no samples, so it carries no third-party license.
